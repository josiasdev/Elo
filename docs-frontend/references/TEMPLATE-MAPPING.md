# Template Mapping

O arquivo `docs/references/template-original.html` é um export SingleFile/Framer do template "Skillora". Ele não deve ser importado diretamente na aplicação. A migração considera padrões de layout e experiência, preservando arquitetura, rotas e dados mockados atuais.

## Decisões

- O CSS minificado do Framer não será reaproveitado diretamente.
- IDs e scripts do template não serão migrados.
- Conteúdo Skillora será substituído por conteúdo EloCiv.
- Layouts serão compostos com componentes pequenos e tokens de marca.
- A landing atual exibe somente Header, Hero, Sobre, Solução, Parceiros, Time e Footer.
- Parceiros e integrantes do time permanecem sem itens reais porque nenhum dado oficial autorizado foi encontrado no repositório.
